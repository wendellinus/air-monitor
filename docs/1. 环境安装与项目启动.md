# 1. 环境安装与项目启动

这份文档只保留真正要做的步骤，按顺序执行即可。

---

## 1. 安装 nvm

**命令**

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

**说明**

- 这个项目先安装 `nvm`，再用 `nvm` 安装指定版本 Node。
- 安装完成后重新打开终端，再继续下一步。

---

## 2. 用 nvm 安装 Node.js 22.18.0

**命令**

```bash
nvm install 22.18.0
nvm use 22.18.0
nvm alias default 22.18.0
```

**说明**

- 这个版本是当前项目文档指定版本，后续不要混用别的 Node 版本。

---

## 3. 启用 pnpm

**命令**

```bash
corepack enable
corepack prepare pnpm@latest --activate
```

**说明**

- 这个项目使用 `pnpm`，不要换成 `npm` 或 `yarn`。

---

## 4. 安装 Docker Desktop

**命令**

无。

**说明**

- 这个项目本地依赖 `PostgreSQL` 和 `Redis`，默认都通过 Docker 启动。
- 所以你不需要额外单独安装 PostgreSQL 和 Redis。
- 安装完成后先打开 Docker Desktop，再继续后面的步骤。

---

## 5. 安装 Git

**命令**

无。

**说明**

- 项目代码拉取、切分支、更新代码都需要 Git。

---

## 6. 这个项目还需要什么

**命令**

无。

**说明**

- 必需软件只有：`nvm`、`Node.js 22.18.0`、`pnpm`、`Docker Desktop`、`Git`。
- 运行项目时还会用到两个外部配置：
- `VITE_AMAP_KEY`，用于前端地图。
- `QWEATHER_*`，用于天气、空气质量、预警数据。
- 这两个不是“软件安装”，但如果没配好，部分功能会没有数据。

---

## 7. 拉取项目代码

**命令**

```bash
git clone <你的仓库地址>
cd air-monitor
```

**说明**

- 后面的所有命令都在项目根目录执行。

---

## 8. 安装依赖

**命令**

```bash
pnpm install
```

**说明**

- 这是 `pnpm install` 之后的唯一准备步骤。
- 如果失败，优先检查 Node 版本和 `pnpm` 是否正确。

---

## 9. 配置环境变量

**命令**

如果文件不存在，先复制模板：

```bash
cp apps/api/.env.example apps/api/.env
cp apps/web/.env.example apps/web/.env
```

后端至少确认这些值：

```env
PORT=8080
DATABASE_URL=postgresql://postgres:123456@127.0.0.1:5432/air_monitor?schema=public&sslmode=disable
REDIS_URL=redis://127.0.0.1:6379/0
JWT_ISSUER=air-monitor
INITIAL_ADMIN_USERNAME=admin
INITIAL_ADMIN_PASSWORD=admin123456
INITIAL_OPERATOR_USERNAME=operator
INITIAL_OPERATOR_PASSWORD=operator123456
```

前端至少确认这些值：

```env
VITE_AMAP_KEY=你的高德 Web JS Key
VITE_AMAP_SECURITY_JS_CODE=
```

**说明**

- 后端环境文件是 [`apps/api/.env.example`](../apps/api/.env.example) 对应的 `apps/api/.env`。
- 前端环境文件是 [`apps/web/.env.example`](../apps/web/.env.example) 对应的 `apps/web/.env`。
- 数据库名统一使用 `air_monitor`。
- `JWT_ISSUER` 统一使用 `air-monitor`。
- `VITE_AMAP_KEY` 不配置的话，地图不会正常显示。

---

## 10. 一键启动

**命令**

```bash
pnpm bootstrap:dev
```

**说明**

- 这条命令会自动完成：
- 启动 Docker 中的 Postgres 和 Redis。
- 按 `DATABASE_URL` 自动创建数据库。
- 执行 Prisma generate。
- 执行 Prisma migrations。
- 执行 seed，初始化账号。
- 构建 `packages/shared`。
- 启动 API 和 Web。

---

## 11. 启动后访问地址

**命令**

无。

**说明**

- API 默认地址：`http://localhost:8080`
- Swagger 默认地址：`http://localhost:8080/api/docs`
- Web 地址以终端输出为准，通常是：`http://localhost:5173`

---

## 12. 初始化账号

**命令**

如果你只想重新执行初始化账号：

```bash
pnpm prisma:seed
```

**说明**

- 默认账号来自 `apps/api/.env`：
- `admin / admin123456`
- `operator / operator123456`
- 如果用户名已经存在，seed 会跳过，不会覆盖原密码。

---

## 13. 常见问题

### 13.1 `pnpm` 命令不存在

**命令**

```bash
corepack enable
corepack prepare pnpm@latest --activate
```

**说明**

- 说明 `pnpm` 还没有准备好。

### 13.2 Docker 不可用

**命令**

无。

**说明**

- 如果命令报错，先打开 Docker Desktop。

### 13.3 `PORT 8080 is already in use`

**命令**

无。

**说明**

- 说明本机已有进程占用了 `8080`。
- 处理方式只有两个：
- 结束占用 `8080` 的进程。
- 或者修改 `apps/api/.env` 里的 `PORT`。
