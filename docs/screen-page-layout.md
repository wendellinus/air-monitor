# ScreenPage 布局说明（用于 Pencil 调整）

目标：在浏览器缩放（放大/缩小）或可用高度变小时，**所有信息都可达**，不出现“被裁切且无法滚动看到”的情况。

对应线框图：`docs/screen-page-layout.svg`

## 结构（从外到内）

1) 根容器
- 高度：`h-dvh`
- 默认不滚动：`overflow-hidden`
- 地图在底层，UI 叠在上层

2) Header（顶栏）
- 固定高度（约 56–64px）
- 内容：标题 / 跑马灯 / 时间 / 管理后台

3) Main（主体）
- 三栏叠加在地图上：左侧栏 / 地图 / 右侧栏

## 左侧栏（固定宽 + 内部滚动）

- 固定宽度：约 `300px`
- 上部：城市概览卡（AQI、发布时间、PM2.5/PM10/O3）
- 下部：热门城市列表（ScrollArea）
- 交互要点：滚轮滚动列表时 **不能触发地图缩放**
  - 做法：在 ScrollArea 外层用 `onWheelCapture/onTouchMoveCapture stopPropagation`

## 地图区（底层交互）

- 点击地图：设置“定位点位（pin）”并联动城市 lookup
- 城市点位：用于“热门城市”快速切换
- 预警点位：有预警时显示，图标内带中文短标签 + 角标数量

## 右侧栏（整体单滚动容器）

问题来源：缩放放大后，右侧 3 张卡总高度可能超过可视高度；如果再嵌套滚动，会出现“底部被裁切/滚轮被地图吞”的体验问题。

解决策略（推荐）：
- **右侧栏整体是 1 个 ScrollArea**（单一滚动轴）
- 里面依次堆叠 3 张卡：`AQI 趋势`、`污染物浓度`、`图例说明`
- 图表高度使用 `clamp`（可压缩），避免在高度不足时把图例完全挤没

交互要点：
- 滚轮在右侧栏上滚动时 **只滚右侧栏，不缩放地图**
  - 同样用 `onWheelCapture/onTouchMoveCapture stopPropagation`

## 图例说明卡片（内容多时靠右侧栏滚动查看）

- 图例内容：2 列网格（图标 / 名称 / 解释）
- 底部说明：角标含义、颜色含义（在卡片最后）
- 在低高度/高缩放下：通过滚动右侧栏，确保能看到卡片底部

## Pencil 调整建议

在 Pencil 里建议按“约束”来画：
- 左栏：固定宽，顶部卡固定高度，列表区域可拉伸并滚动
- 右栏：固定宽，整体滚动，三张卡纵向排列
- 地图：中间自适应填充

如果你希望“图例说明永远完全展示”：
- 需要牺牲图表高度（进一步压缩）或把图例拆成分页/折叠（Accordion/Tabs）
